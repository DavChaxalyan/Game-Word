Game-Word

Overview:

   Game-Word is an engaging word puzzle game where players have 30 seconds to form a correct word from jumbled letters. The challenge lies in the time limit and the scrambled letters that must be rearranged to form the right word.

Game Rules:

   Players are given 30 seconds to guess the correct word.
   The letters of the word are scrambled, and players must rearrange them to form the correct word.
   If the player answers correctly, they receive an additional 10 seconds.
   If the player answers incorrectly, they lose one chance.
   Players have a total of 3 chances to guess the word.
   A hint for the word is provided to assist players.

Features:

   Time Challenge: A countdown timer adds excitement as players race against the clock.
   Hints: Players can use hints to help them guess the word when they're stuck.
   Chances: A three-strike system that adds a layer of difficulty and strategy.

Technologies Used:

   Frontend: HTML, CSS, JavaScript 
   Game Logic: Custom JavaScript functions to handle gameplay mechanics
   Version Control: Git, GitHub
